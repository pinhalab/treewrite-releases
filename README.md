# TreeWrite releases

The published versions of [TreeWrite](https://treewrite.app). Download it at https://treewrite.app/download.

The code of TreeWrite is not public, so the "Source code" files of each release hold only this README.

Each release is immutable. A file of one is checked with `gh release verify-asset <tag> <file> --repo pinhalab/treewrite-releases`.

Support: support@pinhalab.com
